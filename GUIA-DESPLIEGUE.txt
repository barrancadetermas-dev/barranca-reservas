Esta guía te lleva paso a paso desde cero hasta tener tu sistema
funcionando online. Tiempo estimado: 45-60 minutos.

Vas a necesitar:
  ✓ Una cuenta de Gmail o cualquier email
  ✓ El archivo ZIP del proyecto descomprimido en tu computadora
  ✓ Conexión a internet

══════════════════════════════════════════════════════════════════
PARTE 1 — SUPABASE (Base de datos en la nube)
══════════════════════════════════════════════════════════════════

Supabase es tu base de datos. Acá se guardan todas las reservas,
huéspedes, pagos y configuración del hotel.

PASO 1.1 — Crear cuenta en Supabase
────────────────────────────────────
1. Abrí tu navegador y andá a: https://supabase.com
2. Hacé clic en "Start your project" (botón verde grande)
3. Elegí "Continue with GitHub" o registrate con tu email
4. Confirmá el email si te llegó uno de verificación

PASO 1.2 — Crear un proyecto nuevo
────────────────────────────────────
1. Una vez dentro del panel, hacé clic en "New project"
2. Completá los campos:
   → Organization: dejá el que ya aparece (tu nombre de usuario)
   → Name: escribí "barranca-termas" (sin espacios, todo minúsculas)
   → Database Password: inventate una contraseña FUERTE y GUARDALA
     en un bloc de notas. La vas a necesitar después.
     Ejemplo: BarrancaT3rm4s#2026
   → Region: elegí "South America (São Paulo)" — es la más cercana
   → Plan: elegí "Free" (gratis)
3. Hacé clic en "Create new project"
4. ESPERÁ entre 1 y 3 minutos. Vas a ver una pantalla con barras
   de progreso. No cierres la pestaña.

PASO 1.3 — Ejecutar el Schema (crear las tablas)
──────────────────────────────────────────────────
1. Cuando el proyecto esté listo, en el menú izquierdo buscá
   el ícono de base de datos que dice "SQL Editor"
2. Hacé clic en "SQL Editor"
3. Hacé clic en "+ New query" (arriba a la izquierda)
4. Abrí el archivo de tu proyecto:
      scripts/schema.sql
   con el Bloc de Notas o cualquier editor de texto
5. Seleccioná TODO el texto (Ctrl+A) y copialo (Ctrl+C)
6. Pegalo en el SQL Editor de Supabase (Ctrl+V)
7. Hacé clic en el botón "Run" (triángulo verde, abajo a la derecha)
8. Deberías ver "Success. No rows returned" o algo similar en verde
   Si aparece un error en rojo, copialo y consultá a un técnico.

PASO 1.4 — Ejecutar el Seed (datos iniciales del hotel)
─────────────────────────────────────────────────────────
1. Volvé al SQL Editor y hacé clic en "+ New query"
2. Abrí el archivo: scripts/seed.sql
3. Copiá todo el contenido y pegalo en el SQL Editor
4. Hacé clic en "Run"
5. Deberías ver una tabla con "Barranca de Termas" y "7 unidades"

PASO 1.5 — Obtener las claves de conexión
───────────────────────────────────────────
Estas son las "contraseñas" que el sistema usa para conectarse
a tu base de datos.

1. En el menú izquierdo, hacé clic en el ícono de engranaje
   que dice "Project Settings" (o "Settings")
2. Hacé clic en "API"
3. Vas a ver dos valores muy importantes. Guardá ambos en un bloc
   de notas:

   Project URL: https://xxxxxxxxxxxxxxxx.supabase.co
                ↑ Copiá este valor completo

   anon/public key: eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.....
                    ↑ Es un texto larguísimo, copiá todo

PASO 1.6 — Configurar las claves en el código
───────────────────────────────────────────────
1. Abrí el archivo de tu proyecto:
      js/supabase-config.js
   con el Bloc de Notas
2. Buscá estas dos líneas (están cerca del principio):

   const SUPABASE_URL      = 'https://TU_PROYECTO.supabase.co';
   const SUPABASE_ANON_KEY = 'TU_ANON_KEY';

3. Reemplazá 'https://TU_PROYECTO.supabase.co' con tu Project URL
4. Reemplazá 'TU_ANON_KEY' con tu anon/public key
5. Guardá el archivo (Ctrl+S)

   Ejemplo de cómo debe quedar:
   const SUPABASE_URL      = 'https://abcdefgh12345678.supabase.co';
   const SUPABASE_ANON_KEY = 'eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJpc3...';

PASO 1.7 — Crear el usuario administrador
───────────────────────────────────────────
1. En el menú izquierdo de Supabase, buscá "Authentication"
2. Hacé clic en "Users"
3. Hacé clic en "Add user" → "Create new user"
4. Completá:
   → Email: tu email de administrador (ej: admin@barrancodetermas.com)
   → Password: una contraseña segura
5. Hacé clic en "Create user"
6. En la lista de usuarios, copiá el "User UID" (ese número largo
   como: a1b2c3d4-e5f6-7890-abcd-ef1234567890)

7. Volvé al SQL Editor y ejecutá esta consulta REEMPLAZANDO los valores:
   (el rol 'admin' es el que da acceso total al panel; otros roles
   posibles son 'staff' y 'demo', con permisos más limitados)

   DO $$
   DECLARE
     v_hotel_id UUID;
     v_user_id  UUID := 'PEGA-AQUI-EL-UID-DEL-USUARIO';
   BEGIN
     SELECT id INTO v_hotel_id FROM hotels WHERE slug = 'barranca-de-termas';
     INSERT INTO hotel_users (hotel_id, user_id, role)
     VALUES (v_hotel_id, v_user_id, 'admin')
     ON CONFLICT (hotel_id, user_id) DO NOTHING;
   END $$;

8. Hacé clic en "Run". Deberías ver "Success".

PASO 1.8 — Configurar URL de tu sitio en Supabase Auth
────────────────────────────────────────────────────────
(Este paso lo hacés DESPUÉS de obtener la URL de Vercel en la Parte 3)

1. En Supabase → Authentication → URL Configuration
2. En "Site URL" poné: https://tu-proyecto.vercel.app
3. En "Redirect URLs" agregá: https://tu-proyecto.vercel.app/**
4. Guardá los cambios

══════════════════════════════════════════════════════════════════
PARTE 2 — GITHUB (Control de versiones del código)
══════════════════════════════════════════════════════════════════

GitHub es donde se guarda y versiona el código. Vercel lo lee
desde acá para publicar el sitio automáticamente.

PASO 2.1 — Crear cuenta en GitHub
────────────────────────────────────
1. Andá a: https://github.com
2. Hacé clic en "Sign up"
3. Completá: email, contraseña, nombre de usuario
4. Verificá tu email cuando llegue el correo de confirmación
5. Elegí el plan "Free" cuando te lo pregunte

PASO 2.2 — Crear un repositorio nuevo
────────────────────────────────────────
1. Una vez logueado, hacé clic en el botón verde "New" (arriba
   a la izquierda) o andá a: https://github.com/new
2. Completá los campos:
   → Repository name: barranca-termas-pms
   → Description: Sistema de gestión de reservas
   → Visibility: elegí "Private" (privado, solo vos lo ves)
   → NO marques ningún checkbox ("Add README", etc.)
3. Hacé clic en "Create repository"
4. Vas a ver una pantalla vacía con instrucciones. No la cierres.

PASO 2.3 — Subir los archivos del proyecto
────────────────────────────────────────────
El método más fácil para principiantes es subirlos desde el
navegador, sin necesidad de usar la terminal.

1. En la pantalla del repositorio vacío, buscá el link que dice
   "uploading an existing file" y hacé clic
   (O andá a: github.com/TU-USUARIO/barranca-termas-pms/upload)

2. Abrí el Explorador de Archivos (Windows) o Finder (Mac) y
   navegá hasta la carpeta descomprimida del proyecto

3. Seleccioná TODOS los archivos y carpetas dentro de la carpeta
   (Ctrl+A para seleccionar todo)

4. Arrastrá todos los archivos y carpetas al área punteada de
   GitHub que dice "Drag files here to add them to your repository"

   ⚠️ IMPORTANTE: Arrastrá los archivos que están DENTRO de la
   carpeta "barranca-termas", no la carpeta en sí misma.
   La estructura debe quedar:
   index.html (en la raíz, no dentro de otra carpeta)
   css/styles.css
   js/app.js
   etc.

5. Esperá que GitHub los suba. Puede tardar unos minutos.
6. En la parte de abajo ("Commit changes"), dejá el mensaje
   que está por defecto o escribí: "Primera versión del PMS"
7. Hacé clic en "Commit changes" (botón verde)

8. Vas a volver al repositorio y vas a ver todos tus archivos.
   ¡Listo! El código ya está en GitHub.

══════════════════════════════════════════════════════════════════
PARTE 3 — VERCEL (Publicar el sitio online)
══════════════════════════════════════════════════════════════════

Vercel toma el código de GitHub y lo publica como un sitio web
con una URL pública. Cada vez que subas cambios a GitHub,
Vercel actualiza el sitio automáticamente.

PASO 3.1 — Crear cuenta en Vercel
────────────────────────────────────
1. Andá a: https://vercel.com
2. Hacé clic en "Sign Up"
3. Elegí "Continue with GitHub" (importante: usar GitHub para
   que queden conectados automáticamente)
4. Autorizá a Vercel a acceder a tu cuenta de GitHub cuando
   te lo pida

PASO 3.2 — Importar el proyecto
─────────────────────────────────
1. En el panel de Vercel, hacé clic en "Add New..." → "Project"
2. Verás una lista de tus repositorios de GitHub
3. Buscá "barranca-termas-pms" y hacé clic en "Import"
4. Vas a ver la pantalla de configuración del proyecto:

   → Framework Preset: elegí "Other" (no es React ni Next.js)
   → Root Directory: dejalo vacío (punto ".")
   → Build Command: dejalo VACÍO (borrar cualquier texto)
   → Output Directory: dejalo VACÍO
   → Install Command: dejalo VACÍO

5. Hacé clic en "Deploy"
6. Esperá 1-2 minutos mientras Vercel publica el sitio
7. Cuando termina, ves una pantalla de "Congratulations!" con
   una animación de confeti y una URL como:
   https://barranca-termas-pms.vercel.app

8. Hacé clic en "Visit" para ver tu sitio online.

PASO 3.3 — Volver a Supabase a configurar la URL
──────────────────────────────────────────────────
Ahora que tenés la URL de Vercel, volvé al Paso 1.8 de esta guía
y configurá la URL en Supabase Auth.

PARTE 4 — VERIFICACIÓN FINAL
══════════════════════════════════════════════════════════════════

PASO 4.1 — Probar el login
────────────────────────────
1. Andá a tu URL de Vercel: https://barranca-termas-pms.vercel.app
2. Deberías ver la pantalla de login con el nombre del hotel
3. Ingresá el email y contraseña que creaste en el Paso 1.7
4. Si entrás al panel: ¡TODO FUNCIONÓ! 🎉

PASO 4.2 — Probar una reserva de prueba
─────────────────────────────────────────
1. Andá al Calendario en el menú lateral
2. Hacé clic en cualquier celda vacía del calendario
3. Se debe abrir el formulario de nueva reserva
4. Completá los datos de prueba y guardá
5. La reserva debe aparecer en el calendario con color

══════════════════════════════════════════════════════════════════
SOLUCIÓN DE PROBLEMAS FRECUENTES
══════════════════════════════════════════════════════════════════

❌ "Error al cargar la aplicación" al entrar al panel
   → Verificá que las claves en supabase-config.js estén
     correctamente copiadas (sin espacios de más al inicio/final)
   → Asegurate de haber ejecutado el schema.sql y seed.sql
   → Verificá que el usuario esté en la tabla hotel_users

❌ La pantalla de login aparece en blanco
   → Verificá que el archivo index.html está en la RAÍZ del repo
     de GitHub (no dentro de ninguna carpeta)

❌ "Invalid login credentials"
   → El email o contraseña del usuario en Supabase Auth no coincide
   → En Supabase → Authentication → Users, verificá que el usuario
     existe y que el email está confirmado

❌ El calendario no muestra las unidades
   → Verificá que el seed.sql se ejecutó correctamente
   → En Supabase → Table Editor → units, debería haber 7 filas

❌ La cotización del dólar no carga
   → Es normal si hay un bloqueo de CORS en el navegador
   → En producción (Vercel) debería funcionar correctamente

ACTUALIZAR EL SITIO CUANDO MODIFICÁS CÓDIGO
══════════════════════════════════════════════════════════════════

Cada vez que modifiques un archivo del proyecto:

1. Andá a tu repositorio en GitHub
2. Hacé clic en el archivo que modificaste
3. Hacé clic en el ícono del lápiz (Edit this file)
4. Hacé los cambios
5. Hacé clic en "Commit changes"

Vercel detecta el cambio automáticamente y actualiza el sitio
en 1-2 minutos. No necesitás hacer nada más.
