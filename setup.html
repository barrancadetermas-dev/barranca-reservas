🎉 ¡Listo! ¿Qué sigue?

Ya tenés el SQL de configuración. Ahora seguí estos pasos para terminar la instalación.

1️⃣
Ejecutá el SQL en Supabase
Entrá a tu proyecto en Supabase → SQL Editor → pegá el SQL que generamos y hacé clic en "Run".
2️⃣
Creá el usuario administrador
En Supabase → Authentication → Users → Invite user. Luego asocialo al hotel con el segundo bloque SQL.
3️⃣
Configurá las credenciales
Copiá .env.example → .env.local y pegá tu URL y clave de Supabase. O configurá las variables en Vercel.
4️⃣
Publicá en Vercel
Conectá tu repositorio de GitHub a Vercel, configurá las env vars y hacé deploy.
